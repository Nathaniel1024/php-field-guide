# Changelog

All notable changes to this project are documented in this file.

## v1.0.0 - 2026-11-16

### Added
- Initial release of the Modern PHP Field Guide & Starter Kit.
- Framework-free CRUD + API demo app (`public/`, `api/`, `schema.sql`).
- Security-by-default helpers (`CSRF`, output escaping, safe SQL builder).
- Deep-dive docs modules `01` through `10`.
- CLI playground scripts for arrays/strings, dates/money, and modern PHP 8 features.
- Production helper artifacts: health endpoint, deploy checklist script, CI lint workflow.
- Contributor guide and architecture diagrams.

### Notes
- Project targets PHP 8.2+.
- CI runs lint checks on PHP 8.2, 8.3, and 8.4.
